# NewOS Implementation Plan

> **For agentic workers:** Implement this plan task-by-task, in order. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `out/newos-amd64.hybrid.iso`: Debian 13 + XFCE desktop with a kernel.org longterm kernel, tuned for i3 gen2 / 8GB RAM.

**Architecture:** Bash scripts fetch + verify + build the kernel as a `.deb`; live-build assembles a live/installer ISO from Debian trixie with that `.deb`; a QEMU smoke test boots the ISO and checks RAM and boot time reported over serial.

**Tech Stack:** bash, GNU make, kernel `bindeb-pkg`, live-build, QEMU, xorriso, jq, gpg.

**Spec:** `docs/superpowers/specs/2026-11-27-newos-design.md`

## Global Constraints
- Build host: WSL2 Debian 13 (trixie); repo cloned to `~/New_os` (Linux FS), never built from `/mnt/c`.
- Every script starts with `#!/usr/bin/env bash` and `set -euo pipefail`; all text files LF line endings.
- Scripts expose testable functions and only run `main "$@"` when executed directly: `[[ "${BASH_SOURCE[0]}" == "$0" ]] && main "$@"`.
- Kernel: latest `moniker == "longterm"` from `https://www.kernel.org/releases.json`; `CONFIG_LOCALVERSION="-newos"`.
- Boot params always include `preempt=full`.
- Thresholds: idle RAM used < 700 MB; `graphical.target` < 30 s (enforced only with `/dev/kvm`).
- Test runner: `tests/run.sh` runs every `tests/test_*.sh`; helpers in `tests/lib.sh`.

## Review Focus
1. `systemd-analyze` prints `1min 4.512s` or `850ms`, not just `8.2s` → parser must return seconds as a number (Task 3 test).
2. `releases.json` lists several longterm (e.g. `6.6.120`, `6.12.9`) → pick by version sort, not string sort (Task 1 test).
3. Tampered tarball or missing `.sign` → nonzero exit and nothing extracted (Task 1 test).
4. Boot hangs and `NEWOS-MEM` never appears in serial log → FAIL with message, never PASS (Task 4 test).
5. Windows checkout converts scripts to CRLF → `.gitattributes` forces LF (Task 1 check).

### Task 4: Smoke test, Makefile, first ISO

**Files:**
- Create: `tests/smoke.sh`, `Makefile`
- Test: `tests/test_smoke_eval.sh`, fixtures `tests/fixtures/serial.{pass,slow,heavy,hang}.log`

**Interfaces:**
- Consumes: `NEWOS-BOOT` / `NEWOS-MEM` lines from Task 3; `out/newos-amd64.hybrid.iso`.
- Produces: `evaluate <serial.log> <kvm: 1|0>` → exit 0 PASS / 1 FAIL, prints reason. Make targets `kernel`, `iso`, `test` (runs `tests/run.sh` then `tests/smoke.sh`), `clean`.

- [ ] **Step 1: Failing tests:** pass (BOOT 12.1, MEM 540, kvm 1) → 0; slow (BOOT 41, kvm 1) → 1; slow with kvm 0 → 0 and prints `WARN`; heavy (MEM 900) → 1; hang (no NEWOS lines) → 1 with `no NEWOS-MEM`.
- [ ] **Step 2:** `bash tests/run.sh` → FAIL.
- [ ] **Step 3: Implement** `evaluate` (thresholds 700 MB / 30 s per Global Constraints) and `main`: `xorriso -osirrox on -indev ISO -extract /live out/boot`, run QEMU command from spec Task 6 (`-accel kvm -accel tcg`, `timeout 300`), `evaluate out/serial.log $([ -e /dev/kvm ] && echo 1 || echo 0)`. Makefile `iso`: `cd live && sudo lb clean && lb config && sudo lb build 2>&1 | tee ../out/build.log`, then move `live/newos-amd64.hybrid.iso` to `out/`.
- [ ] **Step 4:** `bash tests/run.sh` → PASS.
- [ ] **Step 5:** `make iso` (background, ~30–60 min) → `xorriso -indev out/newos-amd64.hybrid.iso -find /live -name 'vmlinuz*newos*'` finds the kernel. If not found, add `live/config/hooks/normal/9000-copy-kernel.hook.binary` copying `chroot/boot/vmlinuz-*-newos` and `initrd.img-*-newos` to `live/vmlinuz` / `live/initrd.img`, rebuild.
- [ ] **Step 6:** `make test` → PASS.
- [ ] **Step 7: Commit** `feat: smoke test and ISO build`.
